# My Preferences

- Never use markdown blockquotes (the `>` syntax) or literal vertical-bar characters (`|`) in text output to me. They render with a leading vertical bar in my terminal and break copy-paste. To quote or hand over a block of text, use a fenced code block or plain text.
- Never use em dashes (—) in text output to me. Use a comma, period, or parentheses instead.
